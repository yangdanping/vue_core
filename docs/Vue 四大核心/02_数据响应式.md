# 数据响应式

> 响应式所有内容都在 /reactivity 中
> 摆出几个重要概念:响应式数据实现,依赖数据,更新触发,副作用处理

## 响应式数据实现

> 响应式数据实现的本质/关键逻辑:
> reactive -> createReactiveObject({...,mutableHandlers,mutableCollectionHandlers})
> ref -> createRef -> RefImpl 的 toReactive

- proxy + reflect(对于不同数据,响应式规则不同 在 get 代码中track -> 追踪 , 在set 代码 中 trigger -> 触发更新)
- proxy的 get 中追踪依赖数据,set 中触发依赖更新
- defineProperty对比

```ts
const proxy = new Proxy(target, handler) // target 被代理对象, handler 拦截器方法
```

## 依赖数据,更新触发

- 用了哪些数据结构, Map,WeakMap(存 Proxy 对象),Set
- track(收集依赖),trigger(依赖更新后触发视图更新)
