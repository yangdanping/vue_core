# Vue3 编译时

Vue3 的编译流程由三个核心模块协作完成
`compiler-sfc`、`compiler-core`、`compiler-dom`

## 1. compiler-sfc

`compiler-sfc` 是用来处理单文件组件（SFC, Single File Component）的模块。

**主要职责：**

- **解析 SFC：** 将 `.vue` 文件解析为模板、脚本和样式三部分。
- **处理块：** 使用 `compiler-core` 和 `compiler-dom` 对模板部分进行编译。
- **生成代码：** 最终生成包含渲染函数的组件对象。

## 2. compiler-core

`compiler-core` 是 Vue3 的编译核心模块，主要负责将模板转换为渲染函数。

**架构组成：**

- **Parser（解析器）：** 将模板字符串解析成抽象语法树（AST）。
- **Transform（转换器）：** 遍历 AST，进行必要的转换，例如处理指令、插值、事件等。
- **Codegen（代码生成器）：** 将转换后的 AST 转换成 JavaScript 渲染函数。

**通用性：** 这个模块是通用的，可以被用于不同平台（如 web、weex）的编译器。

## 3. compiler-dom

`compiler-dom` 是 `compiler-core` 的一个扩展，专门针对浏览器环境进行了优化。

**功能扩展：** 其架构在 `compiler-core` 的基础上增加了以下功能：

- **DOM 特定的解析与转换：** 处理与浏览器 DOM 相关的特性，例如 HTML 标签、属性和事件。
- **平台特定优化：** 通过优化特定于浏览器的代码生成，来提升性能。
